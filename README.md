# buildsmeta — Сверка сметы с классификатором СМР

Инструмент автоматически проверяет смету генподрядчика против классификатора
строительно-монтажных работ и формирует Excel-отчёт с найденными несоответствиями.

## Установка зависимостей

```bash
pip install -r requirements.txt
```

## Использование

```bash
python checker.py <классификатор.xlsx> <смета.xlsx> [опции]
```

### Опции

| Опция | По умолчанию | Описание |
|-------|-------------|----------|
| `-o`, `--output` | `report.xlsx` | Путь к файлу отчёта |
| `-t`, `--threshold` | `85` | Порог нечёткого сравнения наименований, % |

### Примеры

```bash
python checker.py classifier.xlsx estimate.xlsx
python checker.py classifier.xlsx estimate.xlsx -o отчёт_2026-04.xlsx
python checker.py classifier.xlsx estimate.xlsx -t 80
```

## Структура входных файлов

### Классификатор

Поддерживаются два формата:

**Формат A** — отдельные столбцы для каждого уровня иерархии:
| Раздел | Статья | Позиция | Наименование работы | Ед. изм. |

**Формат Б** — единый столбец с кодом:
| Код | Наименование работы | Ед. изм. |

### Смета

Обязательные столбцы (распознаются по ключевым словам):
- **Кодификатор** — код X, X.Y или X.Y.Z
- **Наименование** — наименование работы
- **Ед.** / **Единицы** — единица измерения

## Структура отчёта

| Лист | Содержание |
|------|-----------|
| **Ошибки** | Только строки с несоответствиями + рекомендации |
| **Статистика** | Сводные числа по типам ошибок |
| **Детализация** | Все строки с отметкой ОК / ОШИБКА / УТОЧНЕНИЕ |

### Типы результатов

- **ОК** — код найден, наименование и ед. изм. соответствуют
- **ОШИБКА — Код не найден** — кодификатор отсутствует в классификаторе
- **ОШИБКА — Наименование не соответствует** — схожесть < порога (по умолчанию 85%)
- **ОШИБКА — Ед. изм. не соответствует** — единица измерения отличается от эталона
- **УТОЧНЕНИЕ — Требуется уточнение детализации** — код уровня X.Y при наличии детализации X.Y.Z
